# TheOreReleases

# Manual Installation

You need to download the latest JAR release and put it somewhere
EXAMPLE ```~/Desktop/TheORE```

Run
```
java -version
```

It should be Version 25 ( Any of them )

if not then go download it, https://openjdk.org/

and then

```
cd ~/Desktop/TheORE
java -jar TheORE.jar
```

Then the game should show
